# Über das Projekt

Dieses Projekt entsteht als technisches Nebenprojekt parallel zum Studium.

Ziel ist die Entwicklung einer autonomen Unterwasserplattform für Freediver und Gerätetaucher.

Im Mittelpunkt stehen:

- Robotik
- Computer Vision
- Unterwassertechnik
- System Engineering

Die Entwicklung wird bewusst öffentlich dokumentiert, um Entscheidungen nachvollziehbar festzuhalten und den Entwicklungsprozess transparent zu gestalten.

Das Projekt befindet sich aktuell in einer frühen Konzept- und Architekturphase.

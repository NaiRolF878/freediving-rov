# Autonomous Freediving ROV

## Vision

Entwicklung einer autonomen Unterwasserdrohne für Freediver und Scuba Diver.

Das System soll:

- autonom einem Taucher folgen
- hochwertige Videoaufnahmen erzeugen
- stabil und leise arbeiten
- langfristig um KI-gestützte Analyse- und Sicherheitsfunktionen erweitert werden

---

# Hauptziele

- zuverlässiger Follow-Modus
- robuste Unterwasserplattform
- cineastische Bewegungen
- modulare Architektur
- schrittweise Erweiterbarkeit

---

# Einsatzbereich

- Freediving
- Scuba Diving
- Pool
- Freiwasser
- Tiefen bis ca. 100 m

---

# Designprinzipien

- Filmqualität hat Priorität
- Stabilität vor Komplexität
- Software zuerst entwickeln
- Hardware iterativ verbessern
- Daten frühzeitig aufzeichnen
- Modularität erhalten

---

# Entwicklungsstrategie

## MVP

Fokus auf:

- Marker-basiertes Tracking
- stabilen Follow-Modus
- Videoaufnahme
- robuste Basisarchitektur

Keine komplexen KI-Systeme im MVP.

---

# Langfristige Vision

- Marker-freies Tracking
- KI-basierte Tauchererkennung
- Trainingsanalyse
- Coaching-System
- Sicherheitsfunktionen
